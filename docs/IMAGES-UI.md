# Image prompts for the new interface (Gemini / Imagen, or any image tool)

Art for the redesigned menus: the phone's wallpaper and app icons, home-screen widget art, the title screen
key art and the loading cards. Put the finished files in `aiImages/ui/` with the file names below and push;
they get cut, compressed and wired in.

**For every image**
- Attach the same style reference you used for the texture sheets, so it matches the game.
- No real brands, logos, app-store icons, celebrities or readable trademarks. The phone is a made-up phone.
- No text in the image unless the prompt asks for it (text gets added in the game, in the right font).
- PNG. Icons on a plain flat background (pure #00FF00 green) so they can be cut out.

---
